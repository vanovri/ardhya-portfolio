prompt-shield-eval — 5-Layer LLM Prompt Injection Defense & Eval Harness

5-layer defense-in-depth prompt injection engine (NFKC/homoglyph/multi-leet normalizer + depth-2 recursive decoding, multi-turn sliding window, 16-ID bilingual EN/ID scorer, 128-bit cryptographic nonce trust boundary, and output canary/4-gram + taint-aware HITL tool gate) paired with a canary-based red-team evaluation harness.

Source on GitHub
01 / Architecture & Stack

Defense-in-depth pipeline

Built in strict TypeScript 5.7 (ESM, zero runtime dependencies) for Node.js 22/24, Vitest, and GitHub Actions CI, aligned with OWASP LLM Top 10 (LLM01, LLM06, LLM07) under the MIT License.

  • Layer 1 — Canonical Normalizer & Depth-2 Recursive Decoder: Strips Unicode Tags, folds NFKC/homoglyphs and multi-leet obfuscations, decodes nested encodings up to depth 2, and replaces HTML/Markdown comment regexes with a linear O(N) scanner to eliminate catastrophic backtracking (ReDoS).
  • Layer 2 — Multi-Turn Sliding Window: Aggregates cross-turn context windows to detect split-payload prompt injections distributed across sequential turns.
  • Layer 3 — 16-ID Bilingual EN/ID Rule Scorer: Deterministic weighted rule evaluation spanning PI-01 through PI-14C across both English and Bahasa Indonesia adversarial phrasing.
  • Layer 4 — 128-Bit Cryptographic Nonce Trust Boundary: Wraps untrusted content in per-request cryptographic delimiters so attacker-supplied tags cannot escape data context.
  • Layer 5 — Output Canary / 4-Gram & Taint-Aware HITL Tool Gate: Inspects model output for canary leakage or 4-gram system prompt exfiltration and forces human-in-the-loop (HITL) approval whenever tainted context attempts privileged tool invocation.

Developed with AI coding assistance. All metrics below come directly from the deterministic local test and red-team harness.

02 / Verified Metrics (Node v24.20.0)

Evaluation, latency & anti-ReDoS evidence

  • Red-Team Evaluation Suite (26 cases: 20 attacks covering 16/16 IDs PI-01–PI-14C + 6 hard negatives): 100% TPR, 0% FPR, 100% Exact Decision Match, and 0 failures on PI-02 & PI-14B.
  • Hot-Path Latency (warm): p50 = 0.054 ms, p99 = 0.620 ms (first cold JIT invocation 11.940 ms; CI latency gate < 5 ms).
  • Fuzz & Anti-ReDoS Suite (17/17 Vitest passed): 480+ deterministic fuzz cases (mulberry32) plus 10 pathological 20–50 KB payloads completing in < 50 ms after replacing HTML/Markdown comment regexes with a linear O(N) scanner.
