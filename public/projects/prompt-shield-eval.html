prompt-shield-eval v1.1.0 — Hybrid LLM Prompt Injection Defense, ONNX INT8 Cascade & MCP Guardrail

Modular 3-export defense-in-depth LLM security engine in strict TypeScript 5.7: zero-dependency sub-millisecond Core (.), optional Layer 3.5 local 104.2 KB ONNX INT8 Semantic Cascade (./semantic), and drop-in MCP Middleware Guardrail (./mcp) targeting autonomous SRE agents (aegis-agent).

01 / Modular 3-Export Architecture

Zero-bloat Core + selective ONNX INT8 + MCP Middleware

Built in strict TypeScript 5.7 (ESM) for Node.js 22/24, Vitest, ESLint 9 (--max-warnings=0), and 3-job parallel GitHub Actions CI, aligned with OWASP LLM Top 10 (LLM01, LLM06, LLM07) under the MIT License. Core runtime isolation (0 dependencies) is locked by both a static transitive import-graph check (scripts/verify-core-zero-deps.mjs) and an isolated clean-room npm pack tarball smoke test in CI.

  • Core (prompt-shield-eval — 0 runtime deps): Layer 1–5 deterministic pipeline (NFKC/Unicode Tag/homoglyph/multi-leet normalizer + depth-2 decode, O(N) linear HTML/Markdown anti-ReDoS scanners, 5-turn sliding window, bounded LRU+TTL TaintSessionStore, 16-ID bilingual EN/ID scorer PI-01–PI-14C, 128-bit cryptographic nonce trust boundary, and output canary/4-gram + strict integer/enum HITL tool gate).
  • Layer 3.5 Semantic Cascade (prompt-shield-eval/semantic — optional peer onnxruntime-node): Fast-path short-circuits obvious attacks at 0 ms ONNX overhead; only gray-zone inputs, subtle storytelling/academic framing (PI-06), and cross-lingual cues (PI-09: FR, ES, JA, DE, ID–EN–regional) escalate to a real 104.2 KB opset-19 INT8 ONNX mini-encoder (DynamicQuantizeLinear + MatMulInteger, SHA-256 verified against models/manifest.v1.json) with hard 25 ms AbortController timeout and explicit failMode.
  • MCP Middleware Guardrail (prompt-shield-eval/mcp — optional peer @modelcontextprotocol/sdk): Transport-agnostic ingress/egress interceptor (InMemory + subprocess stdio) with per-session taint tracking, aegis-agent (HYPERION CH06) 4-tool preset blocking compound indirect hijacks (-32001 TAINTED_CONTEXT_BLOCKED), rejecting float/invalid-enum schemas (-32602), verifying hitl1.* approval tokens, and bridging structured audit events.
