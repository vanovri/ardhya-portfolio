01 / Problem

Problem

Application drafts drift away from what a person can actually prove. I wanted every sentence to trace back to a reviewed fact.

02 / Approach

Approach

Fact ledgerReviewed, evidence-based
Skill comparisonExplicit match to a role

Build gallery

04 / Results

Results

  • No invented claims: drafts are assembled only from reviewed facts, and the optional AI returns fact IDs, never prose.
  • Gaps made visible before drafting: explicit skill coverage separates exposure from hands-on skill, and unresolved requirements are listed.
  • Location assumptions caught: an office address alone leaves the worksite unverified.
  • Traceable, reproducible exports: Markdown/JSON output carries fact IDs, source excerpts and an evidence digest.
05 / Lessons

Lessons

  • Letting AI pick fact IDs, not write claims, keeps drafts honest.
