01 / Problem

Problem

Serial parsers break on real-world byte streams: frames arrive fragmented, malformed or concatenated. Testing that usually needs the hardware attached.

02 / Approach

Approach

FixturesSynthetic UART byte streams
ScenariosFragmented · malformed · concatenated
Virtual timeDeterministic replay
Your parserTested without serial hardware

The kit provides reusable fixtures and a virtual-time replay so parser behaviour can be checked deterministically in ordinary test runs. Built with AI assistance.

04 / Results

Results

Published as a public repository with a v0.1.0 pre-release. No adoption figures are claimed.

05 / Lessons

Lessons

  • It grew out of the UART telemetry work on my EMG thesis, where malformed lines had to be handled safely.
  • Deterministic, hardware-free tests make serial code reviewable.
Release update / 19 Oct 2026

v0.3.0

227 Python tests and three Node tests cover synthetic UART fixtures, virtual-time replay, fault injection, a twin bench and profiling. These fixtures are independent of private thesis data; they do not establish physical serial-link reliability.
