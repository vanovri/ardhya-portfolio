01 / Overview

What I built

A seven-project Python suite covering CRUD persistence with SQLite and Pandas, Matplotlib reporting, cryptographic password generation with secrets and Tkinter, JSON-backed quiz sessions, live REST weather queries with zero-key fallback, filesystem categorization with pathlib and watchdog, HTML extraction with BeautifulSoup/Selenium to CSV, and multi-turn conversational memory with the Anthropic SDK.

Developed with AI coding assistance. A unified dashboard.py Streamlit hub and run_all_demos.py runner execute all seven modules from one workspace.

02 / Evidence

What was checked

All seven modules are verified by an automated pytest suite (tests/test_all_projects.py) and an end-to-end CLI demo runner that generates SQLite records, category/monthly Matplotlib charts, live weather responses, sorted filesystem trees and scraped CSV tables.

Verification run: 24 October 2026. 7 of 7 pytest checks passed on Python 3.14.

03 / Scope

What this demonstrates

Practice implementations with smoke tests across seven modules. The chatbot includes a rule-based local fallback and an optional Anthropic API path. Passing fallback tests does not verify paid API calls, model availability or response quality. Weather and scraping depend on external services or fallback responses. The file-organizer tests operate on temporary demo files.
