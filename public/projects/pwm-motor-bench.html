01 / Overview

What I built

Duel Dyno compares fixed duty and PI control under the same load step. Pit Tuning shows the effect of gain changes on RPM error, overshoot and recovery time. Each run exports 401 simulated samples.

02 / Evidence

What I verified

For a 65% load step, the Redam lonjakan preset reduced peak overshoot from 487 to 263 RPM against the default PI settings. The measured mean absolute RPM error fell from 97 to 72 RPM in the same 10-second simulation.

The model checks and Anatomy geometry audits passed. I verified the tuning controls and CSV export in a desktop browser and the layout at 390 px.

Verified source commit
03 / Scope

Model assumptions

The first-order model uses illustrative motor parameters and a speed-dependent load. All RPM and voltage readings are simulated.
