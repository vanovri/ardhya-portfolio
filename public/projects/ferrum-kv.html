FerrumKV

Rust RESP key-value server with Raft replication, HNSW vector search, BM25 indexing, AOF recovery, and LSM storage.

Source on GitHub
01 / Implementation

What the source contains

The server implements RESP command processing, sharded storage, append-only recovery, Raft replication, a vector index, full-text indexing, and disk-backed storage modules. Cargo.toml declares no external runtime crates.

Developed with AI coding assistance. The linked source files support the implementation summary.
