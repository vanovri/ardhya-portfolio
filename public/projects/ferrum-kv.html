01 / Overview

Zero external crates. Zero unsafe code.

Every line of FerrumKV compiles under #![forbid(unsafe_code)] with an empty [dependencies] table in Cargo.toml and zero .unwrap() or .expect() calls across 24 production modules. A work-stealing TCP reactor parses zero-copy RESP3 frames and live Prometheus HTTP metrics via RespParser::parse_flat_command and zero-allocation get_into, routing keys across 64 CachePadded shards, a 16-stripe tx_exec_fence, and 16,384 CRC16-CCITT cluster hash slots.

Core storage pairs Robin Hood open-addressed hash tables (SipHash-2-4 / FNV-1a), circular ring lists, and level-32 skip lists with Redis Streams (XADD, XREADGROUP, XACK), multi-shard optimistic concurrency transactions (WATCH/MULTI/EXEC), an in-memory RwLock<LsmState> MemTable, and a deterministic SHA-256 stack bytecode VM (EVALSHA).

For analytical and AI workloads, FerrumKV integrates a multi-layer HNSW vector graph with 8-bit scalar quantization (SQ8, 4× memory reduction, 173,007 VSEARCH/s at 93.3% Recall@5), an Okapi BM25 inverted index with LEB128 delta postings, a disk-backed LSM-tree with 4 KB CRC32-verified SSTables, Facebook Gorilla XOR time-series compression, and RFC 8439 ChaCha20-Poly1305 AEAD snapshot encryption.
