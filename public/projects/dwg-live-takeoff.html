Projects/CAD Automation · ezdxf, openpyxl & MCP

Live DWG/DXF Quantity Takeoff Studio (dwg-live-takeoff v0.1.0)

Open-source Python CAD measurement workbench pairing deterministic ezdxf geometry extraction, a live SSE dark viewport, human-in-the-loop Excel BOQ/EAP export, and an 11-tool stdio MCP server (3/3 pytest PASS).

Source on GitHub
01 / Architecture

Deterministic Geometry Takeoff + Live Human Review

  • DWG/DXF Ingestion (parser.py, converter.py): Parses R2018 DXF polylines, closed room polygons (Shoelace area/perimeter), block insertions, and linear conduit runs with $INSUNITS scaling and optional AutoCAD accoreconsole.exe / CADCraft CLI / ODAFileConverter conversion.
  • Real-Time SSE CAD Viewer (viewer_server.py): Localhost viewer with layer visibility toggles, cursor meter coordinates, live step stream, and an HTTP HITL override API (/api/override, /api/export).
  • Multi-Sheet BOQ/EAP Export & MCP Server (boq_export.py, mcp_server.py): Exports BOQ_EAP, Room_Schedule, and Audit_Steps sheets containing live variance and subtotal Excel formulas, exposed alongside 11 stdio MCP tools.
