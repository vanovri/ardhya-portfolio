Multi-Zone Topology

Isolated Git histories. Zero Vercel Rust build minutes.

01

Clean Polyrepo Auditability

Each Rust engine lives in its own focused repository under github.com/vanovri/* so code reviewers inspect pure systems commits without portfolio UI noise.

02

Fail-Closed Provenance Contract

Only zones with a verified summary.json and valid \0asm production binary render VERIFIED LIVE; all others stay explicitly labeled STANDBY PROBE.

03

Edge Isolation & Worker Teardown

Scoped COOP: same-origin + COEP: require-corp + wasm-unsafe-eval unlock sub-microsecond timers while Dedicated Workers terminate cleanly on every zone transition.
