3 Critical Reference Bugs Caught & Fixed

Moving from slide pseudocode to verified local execution uncovered three subtle failure modes that were fixed and locked with regression tests.

Fix #1 · Quantization

Zero-Division & Real 4-Bit Packing

Guarded scale computation with np.maximum((w_max - w_min) / (2**b - 1), 1e-8) for constant tensors and implemented real nibble bit-packing (pack_int4/unpack_int4) instead of float-only simulation.

Fix #2 · World Model

Gradient-Breaking Threshold + TU117 FP16

Removed hard sigmoid thresholding before BCE loss, switched to raw-logit BCEWithLogitsLoss + Soft Dice + GameNGen noise + 8-step DAgger, and added a TU117 cuDNN FP16 NaN bypass for GTX 1650 Ti.

Fix #3 · Game Theory

True Shared-Sequence 0 -> 21 Rules

Replaced broken independent counters with the genuine shared-sequence state machine and proved modulo-4 AI optimality exhaustively across all 21/21 game states.
