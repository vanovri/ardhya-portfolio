Proyek akhir Teknik Elektro UNDIP, 2026

Akuisisi EMG dan GUI Python

Saya menghubungkan sinyal aktivitas listrik otot, pemrosesan STM32, dan layar pemantauan pada proyek rehabilitasi tangan.

Kontribusi saya

Saya mengerjakan subsistem akuisisi dan pengolahan EMG dalam C menggunakan STM32CubeIDE. Saya juga mengimplementasikan seluruh GUI Python/Tkinter, termasuk integrasi data tim. Antigravity dan coding agent membantu penyusunan kode serta problem solving.

Aldin berfokus pada stimulator. Zain berfokus pada rancangan fuzzy control. Implementasi GUI yang saya kerjakan menghubungkan bagian-bagian tersebut. Perancangan fuzzy dan stimulator tetap merupakan kontribusi tim yang berbeda.

Alur dari sensor ke layar

  1. SEN0240Sinyal EMG dari sensor
  2. STM32F411CEU6ADC, sampling nominal 4 kHz
  3. Filter digitalHigh-pass 20 Hz, low-pass 500 Hz, notch 50 Hz
  4. RMS dan MAV400 sampel, jendela nominal 100 ms
  5. UART dan GUI PythonTelemetry, grafik pemantauan, pencatatan CSV

EMG mengukur aktivitas listrik otot. Nilai amplitudo tidak langsung menyatakan kekuatan otot.

Pengujian yang dapat ditunjukkan

Perintah self-test GUI menghasilkan “SELF-TEST PASS (10 kelompok pemeriksaan)” pada pembaruan portfolio ini. Pengujian berjalan tanpa membuka GUI dan mencakup parser, logika safety, serta logger. Ini merupakan bukti pemeriksaan perangkat lunak.

Apa yang diperiksa pada kode

GUI memiliki parser telemetry serial, pengelola komunikasi, logger CSV, grafik EMG, penanganan telemetry, dan fungsi self-test. Firmware memiliki pemrosesan blok ADC, pengolahan fitur, dan komunikasi dengan GUI.

Nama fungsi yang dapat ditelusuri: parse_telemetry_line, SerialManager, CSVLogger, EMGPlot, run_self_test, dan EMG_Process_ADC_Block.

Batas yang perlu dijelaskan

Sampling dan jendela merupakan konfigurasi program. Self-test tidak membuktikan akurasi sinyal fisik, keselamatan perangkat menyeluruh, efektivitas rehabilitasi, atau validasi klinis. Klaim tersebut memerlukan pengukuran dan prosedur uji tersendiri.

Yang saya pelajari

Menguraikan masalah dari sensor sampai tampilan, mengintegrasikan komunikasi serial, dan membedakan konfigurasi program dari hasil pengukuran. Saya menggunakan bantuan AI dengan perhatian pada pemahaman fungsi dan pemeriksaan keluaran.
